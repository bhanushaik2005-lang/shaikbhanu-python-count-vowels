# Python Count Vowels in a String

A simple Python program to count the number of vowels in a given string.

## Author

**Shaik Bhanu**

## Repository Name

`shaikbhanu-python-count-vowels`

## File Name

`count_vowels.py`

## Description

This program accepts a string from the user and counts the vowels (`a, e, i, o, u`) present in the string.

## Features

* Accepts a string from the user
* Checks each character
* Counts uppercase and lowercase vowels
* Displays the total number of vowels

## Requirements

* Python 3.x

## How to Run

Run the program using:

```bash
python count_vowels.py
```

## Example

```text
Enter a string: Hello World
Number of vowels: 3
```

## Algorithm

1. Read a string from the user.
2. Set the vowel count to `0`.
3. Check each character in the string.
4. If the character is a vowel, increase the count by 1.
5. Display the total number of vowels.

## Time Complexity

**O(n)**

## Space Complexity

**O(1)**
